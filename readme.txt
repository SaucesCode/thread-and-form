=== Thread & Form ===
Version: 1.0.0
Requires at least: 6.6
Requires PHP: 7.4
License: GPLv2 or later

An original clothing-brand block theme. Install this folder or its ZIP under Appearance > Themes.
Use Appearance > Editor for templates, navigation, patterns and global styles.
Optional WooCommerce supplies the real product catalog, cart, checkout, and order handling.
Activation does not import content or alter existing posts, products, payments, or settings.
The homepage has a fixed theme layout, editable in the Site Editor (not through the Home page's body).
After editing a template in WordPress, saved database templates override files; reset customizations to see code changes.
Fictional sample branding and generated illustrative images must be replaced/verified before real trading.
See the separate project README and audit for setup and test results.

Assets: original AI-generated fictional campaign/product imagery; see project ASSETS.md for provenance.
Fonts: system Arial/Helvetica/sans-serif; no external font request.
No tracking scripts, custom account endpoints, or payment processing are included.
