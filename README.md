# Thread & Form — multipage WordPress theme

Install this folder directly under wp-content/themes/thread-and-form. Activate it in Appearance > Themes. Then open Appearance > Thread & Form Setup and select Create sample pages. This explicit action creates Home, Collection, About, Journal, Contact, Size Guide, and Shipping & Returns; it preserves existing pages with matching slugs and makes Home the front page.

Edit page copy in Pages and shared styles, navigation and templates in Appearance > Editor. The theme uses native WordPress blocks, so PHP page files are not required. Each page has its own URL and editable content.

WooCommerce is optional. Install/configure it for real product detail, shop, cart and checkout pages. Add actual products in Products. Without it, Collection shows clearly marked sample garments. No payment gateway, working contact form, or shipping promises are included. Do not import the separate development demo into an existing business site.

Sample brand, products and generated images are fictional. Replace contact details, size measurements and policy placeholders before publishing. Theme activation alone does not change the database. Existing saved Site Editor templates may override theme files.
